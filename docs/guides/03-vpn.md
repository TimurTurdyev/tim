# VPN и маршруты: пустить сайты мимо туннеля

Ситуация: включён VPN, он забирает весь трафик, и часть сайтов перестаёт открываться или
работает медленно - банки, маркетплейсы, свои серверы. Нужно, чтобы эти адреса шли напрямую,
а всё остальное - через VPN.

tim делает это маршрутами: для нужных адресов в таблице появляется путь через твой роутер,
мимо туннеля. Это работает для любых программ сразу - браузера, git, ssh, мессенджеров.

## Один сайт или сервер

```sh
tim vpn exclude git.example.com --label git
tim route                         # где сейчас каждая цель: в обход или в туннель
```

Цель сохраняется в конфиг, маршрут ставится сразу. Домен раскрывается во все свои адреса.
Подсеть тоже можно: `tim route add 203.0.113.0/24`.

## Большой сервис целиком

У крупных сервисов поддомены и CDN живут на других адресах. Исключил `yandex.ru` - главная
открылась, а Маркет и Почта нет. Для них нужен не домен, а все сети владельца:

```sh
tim vpn exclude yandex.ru --owner
```

tim найдёт автономные системы, из которых виден домен, и запишет в конфиг их номера, например
`as:13238`. Сети берутся из открытых данных RIPE и обновляются раз в сутки - вписанный руками
список подсетей со временем молча устаревает, этот нет.

Владельцев бывает несколько: у Яндекса адреса видны сразу из двух AS, tim возьмёт обе.
Если сайт сидит на CDN вроде Cloudflare, tim откажется: в обход ушла бы чужая половина
интернета.

## Чтобы не чинить руками после смены сети

Маршрут указывает на роутер конкретной сети. Пересел с домашнего Wi-Fi на офисный - старые
маршруты смотрят на роутер, которого здесь нет, и сайты пропадают, хотя интерфейс тот же.
VPN при переподключении тоже любит забрать маршруты обратно.

Это делает страж - служба, которая раз в 10 секунд проверяет маршруты и чинит сломанные:

```sh
tim route install
```

Нужны права root. Если запустил без sudo, tim спросит и повторит команду сам. Ставится один раз,
дальше о нём можно не помнить: переживает перезагрузку и смену сети.

```sh
tim route status       # когда была проверка, сколько починок и почему
tim route uninstall    # убрать стража; цели и маршруты останутся
```

## Если уже стоял vpn-help

`tim route install` найдёт старый демон `vpn-bypass-routes`, предложит перенести его сети в tim
и снять его - два стража, переставляющие одни маршруты, будут спорить. Перенос можно сделать
и отдельно:

```sh
tim route import --by-owner    # сети заменятся на AS владельцев
```

## Что-то не открывается

1. `tim route` - видно состояние каждой цели. "шлюз устарел" - маршрут от прошлой сети,
   "идёт в туннель" - VPN его забрал.
2. `tim vpn fix` - снять старые маршруты и поставить заново. Со стражем это происходит само.
3. `tim route status` - работает ли страж и что он чинил.
4. `tim net check` - есть ли вообще интернет, DNS и где обрывается.

## Ограничения

- Только IPv4. Если сайт открывается по IPv6, этот трафик останется в туннеле.
- Если VPN-клиент сам умеет "всё, кроме списка", лучше настроить исключения там - это надёжнее
  любых маршрутов. AmneziaWG на macOS этого не умеет, поэтому и нужен tim.
