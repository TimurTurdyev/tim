# Как устроен конфиг

Коротко: в конфиге только то, что tim сам не узнает. Серверы он берёт из `~/.ssh/config`, чей порт -
по папке процесса, стек папки - по её файлам. Поэтому конфиг маленький и почти не устаревает.

Файл лежит в `~/.config/tim/config.toml`, другой путь можно задать через `TIM_CONFIG`.
Пример со всеми разделами: [config.example.toml](../config.example.toml). Что в нём сейчас: `tim config`.

## Что tim понимает сам

| Что | Откуда |
|---|---|
| серверы | все `Host` из `~/.ssh/config`, кроме git-хостов |
| чей порт | git-корень рабочей папки процесса, имя папки |
| кто запустил | окружение процесса: агент и его сессия или ты в терминале |
| стек папки | `artisan` - Laravel, `go.mod` - Go, `package.json` - Node, `pyproject.toml` - Python и т.д. |

## Что лежит в конфиге

```toml
dev = "/Users/me/Dev"                        # папка с кодом, по ней tim disk --deps
sites = ["shop.example.com", "example.com"]  # сайты для обхода
```

**Сайты.** `tim check`, экран Сайты, `tim cert` без аргументов и `tim mail --all` берут их отсюда.

**Свои заготовки сервера.** Команда на чтение, которую хочется запускать с экрана сервера:

```toml
[[recipe]]
  name = "disk-www"
  desc = "место по сайтам"
  run = "du -sh /var/www/* | sort -rh | head"
```

**Куда слать итог обхода.** Раздел `[notify]`: Telegram и ntfy, подробнее - `tim notify --help`.

## Личное

```toml
[shell]
  motd = true            # сводка при открытии терминала

[shell.aliases]
  gs = "git status -sb"

[tunnel]
  host = "prod"          # tim tunnel up без аргументов
```

## Цели обхода VPN

```toml
[[host]]
  addr = "203.0.113.5"   # адрес, подсеть, домен или as:N
  label = "prod"
```

Их заводит `tim direct`, убирает `tim direct rm`. Страж маршрутов берёт цели отсюда и перечитывает
файл каждые 10 секунд, перезапускать его не надо. Адрес и подсеть идут как есть, домен - его адреса
из DNS, `as:N` - сети компании из RIPE, список обновляется раз в сутки. Подробнее: [VPN и маршруты](03-vpn.md).

## Старые поля

`[[project]]`, `[[task]]`, `[[template]]`, `[groups]`, `wrapper`, `editor` и `shell.cd_info` остались
от реестра проектов. tim их не читает, но и не стирает. `tim doctor` скажет, какие есть, убрать их
можно руками. Пока `sites` пуст, сайтами считаются адреса из `url` старых проектов.

## Важно

- tim переписывает конфиг через TOML-кодировщик, комментарии при этом теряются. Прежняя версия
  файла остаётся рядом в `config.toml.bak`.
- `sudo tim ...` работает с твоим конфигом, а не с пустым конфигом root, и после записи
  возвращает файл тебе.
