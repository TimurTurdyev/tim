# Первый запуск

Пять минут от установки до главного экрана. Конфиг руками писать не придётся.

## Поставить

```sh
go install github.com/TimurTurdyev/tim@latest
```

Или из клона репозитория: `make install`. Там же ставятся man-страницы, `man tim` заработает сразу.

## Подключить к shell

```sh
tim init
```

Команда сама найдёт `~/.zshrc` или `~/.bashrc`, допишет туда одну строку и скажет, что делать дальше.
Открой новое окно терминала.

Зачем это нужно. Процесс не может поменять папку у оболочки, которая его запустила. Поэтому
переход в папку с экрана tim идёт через маленькую функцию в shell. Она же подключает дополнение по Tab.

## Сказать, какие сайты твои

Серверы tim находит сам в `~/.ssh/config`. Сайты для обхода - одной строкой в
`~/.config/tim/config.toml`:

```toml
sites = ["shop.example.com", "example.com"]
```

Без списка `tim check` проверит то, что передашь аргументом: `tim check example.com`.

## Попробовать

```sh
tim                # главный экран: беды, разделы, поиск по /
tim ports          # что запущено, в какой папке и кто запустил
tim check          # сайты одной таблицей
tim status         # что происходит с машиной
```

## Если что-то не так

`tim doctor` проверяет конфиг, подключение к shell, `PATH` и менеджеры версий и говорит,
что именно поправить. Справка по любой команде: `tim <команда> --help`, там же есть примеры.
