# Каждый день

Команды, которые удобно запускать по привычке.

## Утро

```sh
tim check
```

Обход всех проектов одной таблицей: что не отправлено в git, отвечают ли сайты, когда кончаются
сертификаты и домены, в порядке ли почта, не попал ли `.env` в репозиторий. Внизу - забытые
dev-серверы и забитый диск.

Чтобы не помнить:

```sh
tim check --install --at 09:30
```

Каждое утро обход пройдёт сам. Уведомление придёт, только если что-то плохо.

## Вход в терминал

```toml
[shell]
  motd = true
```

В каждом новом окне - короткая сводка: машина, проект в текущей папке, сеть и VPN, что запущено.
Отдельно: `tim motd`, разделы - `tim motd repos procs versions`.

## Что сделал

```sh
tim today              # свои коммиты за сегодня по всем проектам
tim today --week       # с понедельника
tim today shop --since 2025-10-01 --md   # списком, чтобы вставить в отчёт клиенту
```

Автор определяется по почте в каждом репозитории, так что рабочие и личные не путаются.

## Компьютер тормозит или кончилось место

```sh
tim top                # кто съел память: браузер одной строкой, а не сорока
tim top --by project   # сколько едят dev-серверы проектов
tim net top            # кто сейчас качает
tim disk --system      # куда делось место: кеши, образы Docker, старые версии IDE
tim disk --clean       # убрать node_modules и vendor заброшенных проектов в Корзину
tim stale --kill       # погасить забытые dev-серверы
tim ps chrome          # что запущено у приложения
tim kill chrome        # закрыть зависшее: сначала как Cmd+Q, потом принудительно
```

## Тренды

```sh
tim stats --install    # замер раз в час
tim stats              # графики за неделю и когда кончится диск
```

## Перейти в проект

`tim go` без аргумента - выбор с поиском, недавние сверху. `tim go shop .` - в папку над клоном.
