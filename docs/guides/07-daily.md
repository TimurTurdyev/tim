# Каждый день

Команды, которые удобно запускать по привычке.

## Утро

```sh
tim check
```

Сайты из конфига одной таблицей: отвечают ли они, когда кончаются сертификаты и домены, в порядке
ли почта. С `--servers` - ещё и серверы. Внизу - забытые процессы и забитый диск.

Чтобы не помнить:

```sh
tim check install --at 09:30
```

Каждое утро обход пройдёт сам. Уведомление придёт, только если что-то плохо.

## Вход в терминал

```toml
[shell]
  motd = true
```

В каждом новом окне - короткая сводка: машина, текущая папка, сеть и VPN, что запущено.
Отдельно: `tim status`, разделы - `tim status procs versions`.

## Что запущено и кем

```sh
tim ports              # порты: папка, кто запустил, сколько работает
tim ports --old --kill # забытое - закрыть по одному
```

Забытым считается процесс, если сессия агента, которая его подняла, закрыта; если агент молчит
дольше 8 часов, а процесс всё работает; или если запущенное вручную работает дольше 8 часов.
Закрыть - Машина › Запущенные, клавиша `x`.

## Компьютер тормозит или кончилось место

```sh
tim hw                 # процессор, видеокарта, память, swap - полосками
tim hw --watch         # то же, обновляется раз в секунду
tim top                # кто съел память: браузер одной строкой, а не сорока
tim top --by project   # сколько едят процессы по папкам проектов
tim net top            # кто сейчас качает
tim disk               # куда ушло место: до конкретной игры, виртуалки, storage
tim disk --system      # кеши, образы Docker, старые версии IDE
tim disk --leftovers   # что осталось от удалённых программ
tim disk --clean       # убрать node_modules и vendor заброшенных проектов в Корзину
tim port 5173          # кто держит порт: что это, папка, кто запустил, где журнал
tim ps qemu            # что запущено; эмулятор Android так и назовётся
tim ps chrome          # что запущено у приложения
tim kill chrome        # закрыть зависшее: сначала как Cmd+Q, потом принудительно
```

Если что-то больше часа ест целое ядро - забытый эмулятор, зависший скрипт, демон сборки, - `tim status`
и `tim check` покажут это строкой "Android-эмулятор Pixel ест почти 5 ядер, без окна, уже 3 дня".

## Тренды

```sh
tim stats install      # замер раз в час
tim stats              # графики за неделю и когда кончится диск
```
